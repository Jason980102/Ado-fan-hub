
# Ado Fan Hub

A free, unofficial, mobile-first companion app for Ado fans worldwide.

> Status: Early Development | Personal Side Project

## Overview

Ado Fan Hub aims to provide an easy-to-use mobile experience for Ado fans to stay updated with official news, social media announcements, concerts, and merchandise releases.

The project focuses on personalized notifications, multilingual support, and convenient access to Ado-related information.

## Platforms

- iOS — Primary
- Android — Primary
- Web — Companion platform

## Planned Features

- Official news and social media updates
- Personalized push notifications
- Merchandise release and restock tracking
- Concert schedules and reminders
- Japanese, English, and Traditional Chinese interfaces
- Region and time zone preferences
- Fan art discovery (#Adoart)
- Optional PayPal support for the developer

Future plans include fan communities and second-hand merchandise exchanges.

## Tech Stack

- Frontend: React Native, Expo, TypeScript, Expo Router
- Backend (planned): Python, FastAPI
- Database (planned): PostgreSQL / Supabase

## Getting Started

Prerequisites: Node.js, npm

```bash
cd apps/mobile
npm install
npx expo start
```
